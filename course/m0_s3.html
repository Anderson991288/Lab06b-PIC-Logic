M0 s3　共用光學模型：MZI 的 2×2 矩陣 T(θ, φ) 與單元測試

光運算邏輯 PIC 實作課程｜模組 M0 環境與元件基礎｜第 3 步

這一步要回答：M0 s2 用 FDTD 看到的 MZI 行為，能不能濃縮成一個 2×2 複數矩陣？這個矩陣怎麼確認寫對了——而且「確認」本身可信嗎？

交給下一步：全課程共用的 common/mzi.py（T2、embed 等）與它的單元測試。M1 用 7 個 T2 嵌進 5×5 矩陣組成 B7，M2 s2 再拿 PDK 電路模型和它比。

白話範例：FDTD 像是拍一段光在晶片裡跑的影片，每拍一次要好幾個小時。矩陣模型像是把影片整理成一張「輸入 → 輸出」的換算表：給兩個入口的光（振幅與相位），乘上這張 2×2 表，就得到兩個出口的光。B7 有 7 顆 MZI、M1 要算 80 組真值表，只有換算表算得動；但換算表必須先和影片對得上。

① 模型與符號慣例

光由左往右經過：φ 相位段 → 2×2 耦合器 H → θ 相位段 → 2×2 耦合器 H。兩個相位段都在索引 0 的臂上。

項目寫法意義
耦合器H = [[1, i], [i, 1]] / √2理想 50:50；跨到另一條波導的光多 90° 相位（i）。
MZIT(θ, φ) = H · diag(eiθ, 1) · H · diag(eiφ, 1)矩陣由右往左讀＝光由左往右走。
功率直通 |T00|² = |T11|² = sin²(θ/2)；交叉 = cos²(θ/2)θ＝0 全交叉、θ＝π 全直通、θ＝π/2 各半。
φ 的作用只改變兩路輸入的相對相位單一輸入時不影響功率；兩路相干輸入時決定合到哪一路（B7 靠它對齊參考光）。
非理想loss_db：振幅乘 10−dB/20；mmi_err=(ε1, ε2)：耦合器直通功率 1/2＋εM2 以後才用；這一步只用來檢查測試與解讀 FDTD。
與佈局的對應layout_to_model()：佈局 (in1, in2) ↔ 模型索引 (1, 0)M0 s2 的 Meep 佈局把 θ 段放在上臂（in2／out2 那一側），所以埠 2 是模型的索引 0。
為什麼要寫清楚索引：θ 放在哪條臂、H 的 i 放在哪裡，單一輸入時看不出差別（功率一樣），但兩路相干輸入時，輸出會整個換到另一路。M1 的 B7 全部是相干輸入，所以符號慣例錯了，真值表會整片錯，而且 θ=0／π 的測試抓不到。下面 ③ 的 F5、F6 就是這種錯。

③ 故障注入：測試真的抓得到錯嗎？

⑤ 非理想的等效：差異從哪裡來

如果差異只是 θ 多了一個固定偏移，θ=0 與 θ=π 反推出的偏移應該大小相同、方向相反；實際是 +4.1° 與 -6.5°，而 θ=π/2 是 +2.1°。所以 θ=0／π 的漏光（0.13%、0.32%）不是單純相位誤差：理想耦合器的 MZI 消光比是無限大，有限消光比需要非理想項。

判讀：等效 ε 比單顆 MMI 的實際分光誤差大兩個數量級，所以它不是 MMI 的分光比誤差，而是把其他效應一起吸收的「等效值」。可能的來源包括 MMI 跨接相位不剛好 90°（coupler(ε) 只描述功率不平衡，不描述相位）、θ 段折射率台階的反射與模態失配（θ=π 的 Δn 最大，漏光也最大）。要分開這些來源需要 FDTD 輸出相位，本課程沒有做。這些差異都在 0.02 以內，M1 用理想模型的結論不受影響。

⑥ 對照：另一套獨立實作

這一節是什麼：同一份課程另有一套獨立完成的實作（以下稱實作 B，檔案在 impl_b/）。兩套各自寫程式、各自跑結果。本頁其他各節是課程主線（實作 A）。

約定一致

兩套都採用 T(θ,φ)＝H·diag(eiθ,1)·H·diag(eiφ,1)，索引 0＝上臂（θ、φ 所在的一側，PDK 的 in2）。兩套是各自寫出來的，約定卻一致，這代表從原始教材讀出的定義沒有歧義。實作 B 另外提供轉換函式 to_lower_first（T下方優先＝P·T·P），給習慣「索引 0＝下方」的程式使用。

實作 B 才有、值得一起看的內容

  • 逐步追光場：輸入 → 經過 φ → 第一個 MMI → 經過 θ → 第二個 MMI → 損耗，每一步的複數振幅都列出來，手算時可以逐格對答案。
  • 平手的讀取：|ΔP| ≤ ε 時回傳「無法判定」，而不是硬判成 0 或 1。
  • 相位換算長度：π 相位差相當於臂長差 ΔL＝λ/(2neff)＝0.329297 µm。版圖上不到 0.33 µm 的長度差就讓 MZI 從全交叉變成全直通，這是 M2 要求兩臂等長的原因。

⑦ 判讀練習

題目怎麼做要寫出的結論
1. 手算把 θ=π/2、φ=0 代入 T(θ, φ)，乘上 v = [1, 1]/√2 與 [1, −1]/√2。兩個輸出分別全部到索引 0、索引 1：同一顆 MZI，輸入相位不同，輸出就不同。
2. 換算佈局M0 s2 合光案例的輸入是 in1 = 1/√2、in2 = eiπ/√2。用 layout_to_model 換成模型索引後再乘 T。得到 out1 = 1、out2 = 0，與 FDTD 的 0.999／0.001 一致。
3. 讀故障表挑 ③ 表中只被一項測試抓到的故障。如果刪掉那一項測試，這個錯就會溜進 M1；說明那一項測試保護的是什麼物理性質。
4. 讀等效參數比較 ⑤ 的等效 ε 與單顆 MMI 的 FDTD 分光誤差。兩者差兩個數量級：等效參數能「重現」數據，不等於找到原因。

⑧ 限制

  • 理想模型：M1 只用理想 T(θ, φ)（無損耗、50:50）；非理想參數留給 M2 與 PDK 電路模型。
  • 對照只有四個點：FDTD 只跑了 θ = 0、π/2、π 與一個合光案例，θ 掃描曲線的其他位置沒有 FDTD 驗證。
  • 沒有相位資料：M0 s2 只量功率，沒有輸出相位，所以無法直接檢查 T 的相位項；相位要等 M1 的相干運算（真值表）間接驗證。
  • 等效參數不傳下去：⑤ 的擬合只說明差異的大小，不作為後續設計參數。

⑩ 驗收條件

  • 單元測試全部通過。
  • 故障注入每一種都至少被一項測試抓到。
  • 模型與 M0 s2 的理想值完全一致（差 < 1e-12），確認兩邊的符號慣例對上。
  • 模型與 FDTD 除以總穿透後的最大差 < 0.05（與 M0 s2 相同標準）。
