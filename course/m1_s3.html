M1 s3　B7 讀取計算：v → y = U·v → 功率 → ΔP → 0／1

光運算邏輯 PIC 實作課程｜模組 M1 用一群 MZI 實現邏輯｜第 3 步

這一步要回答：給一組輸入位元，怎麼一步一步算到 0 或 1？o2、o4 的光場是哪些輸入加起來的？ΔP 裡哪一部分來自參考光 R、哪一部分來自資料光彼此的干涉？

交給下一步：完整的讀取計算與 ΔP 的二次式 readout_form。M1 s4 換上真正的邏輯相位，用同一套計算檢查 80 筆真值表，並用這裡的拆解看懂為什麼 XOR 的餘裕比較小。

白話範例：o2 是一個「加權投票箱」：每一路輸入丟進一支箭頭（權重 u 乘上輸入振幅），箭頭首尾相接，最後量總箭頭的長度平方。o4 是另一個投票箱。比較兩箱的分數，o2 大就是 1。權重由 14 個相位決定；同一組權重下，不同輸入丟進不同的箭頭，結果就不同。

① 四個步驟

步驟算什麼注意
1. 編碼v = [x1, x2, x3, x4, R]，R = 3放的是振幅。R 的功率是 9，但向量裡寫 3。
2. 混合y = U·v；o2 = Σ u2k·vk、o4 = Σ u4k·vku 是複數，乘完先加起來（箭頭相加）。
3. 偵測P(o2) = |o2|²、P(o4) = |o4|²光偵測器量的是功率；平方在相加之後。
4. 判定ΔP = P(o2) − P(o4)；> 0 判 1、< 0 判 0ΔP = 0 是邊界，判不出來。|ΔP| 越大越不怕雜訊。

本頁全部用 M1 s2 的示範設定（7 顆 MZI 都是 θ = π/2、φ = 0）。它不是任何一種邏輯閘的設定，只是方便手算、而且和原版課程的數字可以逐項對照。

③ ΔP 的四種來源

把 o2 = w₂·x + u₂₅R 代入 |o2|²，再減去 o4 的同樣展開，ΔP 對位元 x 是一個二次式：

ΔP(x) = c₀ + Σ akxk + Σk,l Qklxkxl

部分式子與 R 的關係意義
只有 Rc₀ = R²(|u₂₅|² − |u₄₅|²)∝ R²輸入 0000 時的 ΔP；決定「全暗」判 0 還是 1。
R × 資料ak = 2R·Re(u₂₅*u₂k − u₄₅*u₄k)∝ R每個位元的「票數」，對位元是線性的。
資料自己Qkk = |u₂k|² − |u₄k|²無關位元 k 自己的光到兩個讀取埠的功率差。
資料 × 資料2Qkl（k ≠ l）無關兩路資料光彼此干涉；XOR 這類「一條直線分不開」的函數只能靠它。
  • 只有 R：c₀ = -0.000。示範設定下 R 到 o2、o4 的功率相同，所以 0000 落在邊界。
  • R × 資料：a = [+0.375, +1.125, -1.500, +1.500]（x1–x4 各自的票數）。x3 的票是負的，所以 x3=1 時傾向判 0。
  • 資料 × 資料：非對角 Q 最大 0.500；影響最大的是 1011（-1.500）。餘裕最小的是 0111：ΔP = +0.063，R×資料 +1.125 幾乎被資料×資料 -1.000 抵銷。
  • 核對：四部分加總與直接計算的最大差 1e-15。

  • 功率相加（錯在步驟 2、3 的順序）：丟掉 R×資料 與 資料×資料 兩項，示範設定下判錯 10/16。隨機相位下平均只錯 1.8 組，是因為隨機相位的 c₀（∝ R²＝9）通常很大，兩種算法共用它；邏輯相位的判定靠的正是被丟掉的兩項，M1 s4 會用真正的相位再檢查一次這個錯的後果。
  • 取模長不平方（錯在步驟 3）：|o2| − |o4| 與 |o2|² − |o4|² 永遠同號，所以判定一組都不會錯（隨機相位 0 組），但 ΔP 的大小錯了：用它估餘裕會低估雜訊容忍度。判定正確不代表計算正確。
  • R 放成 9（錯在步驟 1）：示範設定下剛好沒判錯，隨機相位下平均錯 1.4 組：R 的比重被放大，改變 R 與資料之間的平衡。
  • 讀錯埠、忘了 R：隨機相位下平均判錯 6.2、9.5 組。忘了 R 時 0000 永遠是 0，回到 M1 s1「沒有光就讀不到 1」的限制。

⑥ 對照：另一套獨立實作

這一節是什麼：同一份課程另有一套獨立完成的實作（以下稱實作 B，檔案在 impl_b/）。兩套各自寫程式、各自跑結果。本頁其他各節是課程主線（實作 A）。

同一個手算，換一組相位

主線用示範相位（θ＝π/2）手算 1000 與 1100；實作 B 直接用 AND2 的相位手算同樣兩個輸入：

輸入主線：示範相位實作 B：AND2 相位
1000ΔP＝+0.4375（判為 1）ΔP＝−2.115379（判為 0，AND 的正確答案）
1100ΔP＝2.0ΔP＝+2.115379（判為 1）

兩邊各自都對。示範相位不是任何邏輯閘，所以 1000 判成 1 不算錯；換成 AND2 相位，同一個流程就得到 AND 的真值。建議學員兩組都算一次。

實作 B 才有、值得一起看的內容

  • 自身項與干涉項分開算：例如 1100 在 out1 的功率＝2.4615（各路自身）＋4.0961（干涉）。干涉項比自身項還大，所以相位一錯，結果就翻轉。
  • 三種常見算錯：
    • 先取功率再相加：得到 −5.077，連正負號都錯。
    • 用振幅差代替功率差：得到 0.4531。
    • 矩陣某一列取了共軛：光場差 4.46，ΔP 卻只差 7.75×10−9。只比 ΔP 會以為沒錯，所以檢查要比到光場。
  • 邊界規則：|ΔP| ≤ 10−10 視為無法判定；例如 10−12 就屬於邊界。

⑦ 判讀練習

題目怎麼做要寫出的結論
1. 手算用 ② 表中 u₂k、u₄k 的數值，自己算輸入 1000 的 o2、o4、功率與 ΔP。o2 = 1 + i、P = 2；o4 = −1 + 0.75i、P = 1.5625；ΔP = 0.4375，判 1。
2. 功率是 2 還是 √2o2 = 1 + i 的功率是多少？|1 + i|² = 2；√2 是光場的長度，不是功率。
3. R 為什麼乘 3算 o2 時，u₂₅ 要乘 3 還是 9？乘 3（振幅）。9 是 R 的功率，只會出現在平方之後的 c₀。
4. 讀分解圖在圖 M1-s3-2 找出 0111 的四個部分。R×資料 +1.13、資料自己 −0.06、資料×資料 −1.00，總和只剩 +0.06：資料光彼此干涉幾乎把 R 的票數抵銷，這一組的餘裕很小。
5. 全暗輸入為什麼示範設定下 0000 是邊界？c₀ = R²(|u₂₅|² − |u₄₅|²)，示範設定下 R 到 o2、o4 的功率剛好相同。真正的邏輯相位必須讓 c₀ 不為 0，0000 才有明確的答案。

⑧ 限制

  • 示範相位：本頁的 16 組結果不是任何邏輯閘；真正的 AND、OR、XOR 等在 M1 s4。
  • 理想、無雜訊：ΔP 的正負只在理想模型下有意義；實際系統要求 |ΔP| 大於雜訊與元件誤差，M1 s4 用「最小 |ΔP|」當餘裕。
  • 相干光：資料光與 R 必須同一雷射、相位固定，否則 R×資料 與 資料×資料 兩項會隨時間平均掉，只剩功率相加（④ 表的第一種錯）。
