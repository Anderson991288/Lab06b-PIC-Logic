對照：另一套獨立實作

這一節是什麼：同一份課程另有一套獨立完成的實作（以下稱實作 B，檔案在 impl_b/）。兩套各自寫程式、各自跑結果。本頁其他各節是課程主線（實作 A）。

約定一致

兩套都採用 T(θ,φ)＝H·diag(eiθ,1)·H·diag(eiφ,1)，索引 0＝上臂（θ、φ 所在的一側，PDK 的 in2）。兩套是各自寫出來的，約定卻一致，這代表從原始教材讀出的定義沒有歧義。實作 B 另外提供轉換函式 to_lower_first（T下方優先＝P·T·P），給習慣「索引 0＝下方」的程式使用。

實作 B 才有、值得一起看的內容

  • 逐步追光場：輸入 → 經過 φ → 第一個 MMI → 經過 θ → 第二個 MMI → 損耗，每一步的複數振幅都列出來，手算時可以逐格對答案。
  • 平手的讀取：|ΔP| ≤ ε 時回傳「無法判定」，而不是硬判成 0 或 1。
  • 相位換算長度：π 相位差相當於臂長差 ΔL＝λ/(2neff)＝0.329297 µm。版圖上不到 0.33 µm 的長度差就讓 MZI 從全交叉變成全直通，這是 M2 要求兩臂等長的原因。
