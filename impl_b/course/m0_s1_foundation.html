M0 S1 補充｜理想 MZI 光場實驗

先不用製程工具，親手跑一個理想 MZI：確認環境、預測輸出、驗證結果，並留下自己的學習證據。

教材與基礎實驗已驗證學員提交待完成
本步問題：我能否在自己的工作目錄執行同一份程式、得到相同的相位／功率結果，並把環境與輸出留下來？
預計 60 分鐘：讀目標 5 分 → 盤點 15 分 → 實驗 20 分 → 比較原圖 10 分 → 作答 10 分。

1．今天要完成什麼

  1. 能指出根目錄、主報告、程式、config 與 evidence 分別在哪裡。
  2. 記錄實際 Python 路徑與版本，知道 EDA 工具有哪些尚待驗證。
  3. 親手跑五個理想 MZI 案例，分清光場相加與功率相加。
  4. 用自己的話解釋「改相位會改輸出」，並提交學習記錄。

不需先裝 IPKISS、Meep 或 NumPy；本步腳本僅使用 Python 標準函式庫。這讓第一個實驗可以先建立可重現的基準，下一步再驗證實際製程工具。

2．先預測，再執行

先看圖，將答案記在下方學習記錄：光只從下方 in1 輸入，θ=0 時，最後會從哪一個輸出離開？若 θ=π/2，會不會每路各得到一半？兩路同時輸入時，總輸入功率應如何固定？

一顆理想 MMI 的光場混合規則為 H=[[1,i],[i,1]]/√2；此處 MZI=H·diag(1,eiθ)·H。先將兩路複數光場相加，輸出功率才是 |E|²。兩個相同功率、不同相位的輸入，可能完全走向不同輸出。

常見問題與修正
  • python 指向 Windows Store：改用確實存在的 python.exe 完整路徑；盤點 JSON 會記錄 sys.executable。
  • ModuleNotFoundError：本步兩個腳本不需第三方套件。若是後續 EDA，確認目前 Python 是否是授課環境。
  • 找不到檔案：確認根目錄是 C:\EDA_Codex\Lab06b，腳本會以自身位置計算相對路徑。
  • 5/5 失敗：先核對上下埠順序、θ 加在哪一臂、MMI 的 i 與 1/√2，以及是否先求光場再取模平方。
  • EDA readiness 未驗證：在未提供 EDA 工具鏈的環境為預期狀態；它不影響理想模型基礎實驗的執行。
