光運算邏輯 PIC 實作課程

以學員實際動手，從 MZI 邏輯到完成一顆單 B7 光子晶片（PIC）設計資料包｜總目錄｜2026-10-31

課程目標：學員在自己的工具鏈上，依序做出一顆 4-bit B7 光邏輯 PIC：看懂 MZI 如何用光做 AND／OR／XOR → 用模型驗證 80 筆真值表 → 用 IPKISS＋CORNERSTONE PDK 寫出佈局 → Review、配置 EC 光學 I/O 與 heater PAD → DRC 與連接檢查 → 交付可重現的設計資料包。

與原版課程的差別：原版是講師把既有結果整理成教材；本課程每一步都要學員在自己的電腦重新執行，由程式產生證據 JSON，再由證據產生頁面。沒有重跑的內容一律標「引用」。

M0 s3共用光學模型與單元測試通過T(θ,φ) 模型 13 項單元測試全過；7 種故障注入全部被抓到；與 M0 s2 FDTD 四種狀態最大差 0.019。
M1 s1光訊號與邏輯：輸入、混合、讀取通過B7 標註圖由共用定義產生；單顆 MZI 做得到 7/14 種 2 輸入邏輯（正好是 00→0 的那些），加參考光 R 後 14/14；R 放大線性可分函數的餘裕，XOR 不受益。
M1 s2B7 組成：7 顆 MZI → 5×5 矩陣 U通過矩陣相乘、逐層追蹤、路徑展開三種算法一致；10 項測試含手動追蹤排列與原版 U 兩組黃金值；7 種組裝錯誤全部被抓到；x4、R 永遠到不了 o1。
M1 s3B7 讀取計算：v → U·v → 功率 → ΔP → 0／1通過1000、1100 手算與原版一致；ΔP 寫成位元的二次式並拆成 R²、R×資料、資料自己、資料×資料四部分（加總誤差 1e-15）；五種常見算錯的後果。
M1 s4可程式邏輯：換 14 個相位就換功能通過80/80 正確、與原版逐列一致；XOR2 餘裕 0.25（AND2、OR2 約 2.1），拿掉交叉項就錯；FDTD 等效誤差下仍全對；相位誤差 σ ≤ 0.02 rad 全對；自行求得 NAND2 相位。
M1 s5功能規格交給 M2通過規格（光路、10 個光學埠、14 個相位通道、讀取規則、驗收與相位精度 0.02 rad）與相位檔分開、以 SHA-256 綁定；80 筆交接真值表；獨立檢查 10/10，7 種規格寫錯全部被抓到。
M2 s1PIC 邊界：晶片上／晶片外通過功能方塊圖與 25 項 I/O 表由規格產生；外部設備容忍度：PD 不平衡 −21%～+31%、R 振幅 ±13%、R 相位 −33°～+42°、消光比 ≥ 18.3 dB、資料振幅 σ 2%；AND4 對 R 最敏感。
M2 s2電路模擬：PDK 元件組成 B7通過連接表只由規格產生（7 MZI、9 條連線、10 個外部埠）；IPKISS／Caphe 80/80，U 與 NumPy 差 1e-15；7 種接線錯誤全部抓到（o1／o5 對調只有比對 U 才抓得到）；PDK 電路模型是理想的；兩臂長度規則 ΔL×|Δλ| ≤ 1.8×10⁻³ µm²。
M2 s3IPKISS＋Python 核心佈局通過MZI 與 B7 核心 GDS（2076×177 µm）DRC 0 違規；IPKISS 從佈局抽出的連接表與規格一致；旁路與 MZI 臂等長（510.133 µm），佈局電路 80/80 且 1530–1570 nm 都不用重新校正；5 種佈局錯誤分別由 DRC、抽連接表、等光程檢查抓到。
M2 s4Layout Review通過只讀 GDS 與規格的 8 項審查全部通過（放置、光學埠、Si 最小間隙 0.53 µm、20 段路徑等長、14 個 heater 對規格通道、28 個接觸墊、金屬間距、設計區）；5 個故障版 GDS 都被抓到；待補 EC、接墊與回流（M2 s5）。
M2 s5晶片介面佈局：EC、接墊、回流通過晶片 3876 × 1200 µm，核心原樣放入；10 個自建薄矽尖端 EC、等長扇入（差 2×10⁻⁵ µm）；單層金屬「訊號在內、回流在外」，14 訊號網＋2 回流網無短路開路；DRC 0；晶片電路 80/80（1530–1570 nm）；4 種介面錯誤都被抓到。
M2 s6DRC 與連接檢查、簽核通過凍結版 DRC 0（30 條規則；12 條用到的規則與設計區都以故障注入確認會觸發）；只讀 GDS 的光學 LVS（自行辨認 14 個 MMI、33 條導線）與規格一致；14 個 heater 接線正確（加熱絲 111.11 方塊）；6 個故障版都被抓到；產生 b7_chip_checked.gds 與簽核表。
M2 s7完成交付通過交付包 B7_PIC_delivery.zip（53 個檔案：版圖、報告、介面表、模擬、原始碼、README、SHA-256 清單）；解壓後只用包內檔案重驗：清單、只讀 GDS 的 LVS／電氣、用包內程式重建 GDS 逐多邊形相同、DRC 0；竄改 1 位元組會被抓到。Virtuoso 批次匯入／匯出（8191 點匯出與簽核版幾何相同；預設 200 點會切開曲線，平台規則報 16 個線寬違規）；自行改寫的 Calibre 規則與 KLayout 逐條一致（規則故障 12/12、邊界案例 11/11）。
M3 s1從零重建通過rebuild_all.py 在乾淨資料夾依序重跑 20 支程式（約 7 分鐘，Meep 光場以 SHA-256 沿用）；126 個產出檔：70 個位元相同、56 個內容等價、0 個不同；最終 GDS 多邊形相同、80 筆與簽核、交付重驗都通過；改相位檔時下游會停下。
M3 s2換一種方法檢查通過自寫的邊對距離檢查（Python／Shapely／SciPy）與 KLayout 逐項對照：最終 GDS 兩邊都 0 違規，最小線寬 Si 0.350、薄矽 0.250 µm（餘量 0）、Si 最小間距 0.53 µm；規則故障注入 12/12、邊界案例 11/11 一致；拿掉 45° 夾角限制會多出標記。

完整規劃

四個模組、17 步，建議約 18 小時（M0 3.5 h、M1 5 h、M2 8 h、M3 1.5 h）。每一步固定六段：這一步要回答 → 白話範例 → 學員操作 → 檢查結果（由證據產生）→ 驗收條件 → 程式、檔案與歷史。主作業固定單顆 B7；原版的 B7×2 晶片只作講師參考。

補充：MZI／MMI 光場傳播圖分析（M0 s2 已重跑）

用 Meep FDTD（2D 有效折射率法，CW 1550 nm，時間平均 |E|²）畫出光在元件內的傳播。B7 的每一格都是同一種 MZI，所以這組圖正好是學員「看見」M1 邏輯運算的物理基礎。M0 s2 已用本課程的工具鏈重跑（PDK MMI 幾何、24 px/µm），下表把參考研究的數值與重跑結果並列；圖與完整表格見 M0 s2 ④。

MZI 切換in1、θ=0 → out2 0.79、out1 0.002（約 26 dB）out2 0.932、out1 0.001（29.0 dB）B7 某格的 θ 讓光「整路改道」；對應 T(θ=0) 的交叉態。
MZI 直通in1、θ=π → out1 0.78、out2 0.013（約 18 dB）out1 0.930、out2 0.003（25.0 dB）θ 加 π，光從交叉改成直通。
MZI 分光in1、θ=π/2 → 0.38／0.39（≈ 49.5:50.5）0.478／0.444（≈ 51.9:48.1，θ 約多 2°）|out1|²=sin²(θ/2)、|out2|²=cos²(θ/2)；θ 連續可調 = 加權和的權重。
MZI 合光in1＋in2 各半、相差 180°、θ=π/2 → out1 0.77、out2 0.002out1 0.921、out2 0.001（28.8 dB）相干性：只有相位對才全部合到一路。這就是 B7 要用參考光 R、要先加光場再取平方的原因（M1 s3 的交叉項）。
1×2 MMIW=6 µm、L=31.0 µm：T=0.988、0.500／0.500引用 未重跑（B7 不使用）自成像：中段三重像、末端兩個等強像。

判讀時必須講清楚的限制：(1) MZI 總穿透（參考研究 0.77–0.79、重跑 0.92–0.93）主要是 2D 有效折射率法與網格的數值損耗，解析度提高就上升，不是元件損耗（實測 2×2 MMI 每顆約 0.33 dB）；(2) 為縮短模擬，臂直段取 20 µm（實際佈局 122 µm），θ 以上臂核心 Δn 等效——參考研究用經驗係數 ÷1.07 校正，重跑改由 Γ=∂n_eff/∂n_core 解析換算；(3) 只模擬 TE、2D。學員作業要把這三點寫進判讀表，不能把場圖亮度直接當成損耗。

學員要交的分析：① 在每張圖標出 MMI1、兩臂、MMI2 與輸出位置；② 由切換、直通與合光的數值算消光比（dB），並與 sin²／cos² 理論對照；③ 用 M0 s3 的 T(θ,φ) 重算四種狀態，說明模型與 FDTD 差在哪；④ 比較上表兩欄：除以總穿透後比例一致，總穿透差異來自解析度與幾何。

相對原版課程 HTML 的優化

原版現況本課程做法
單一學習頁約 254 KB，M1／M2 全擠在一頁；沒有 M0。一步一頁（course/m0_s1.html…），本頁為總目錄；補上 M0 環境、元件物理與共用模型。
結果寫在產生頁面的程式字串裡，數字與證據可能不同步。每步 out/*.json 為證據，頁面結果區由 build_page.py 從 JSON 產生。
多處「本次未重跑 EDA」，讀者分不清哪些是新結果。每項狀態用標章：通過／失敗／未安裝／等待／引用。
程式寫死安裝路徑，搬家後失效。統一讀 EDA_paths.json；頁面不出現本機路徑。
只有淺色版面，表格在手機會擠出畫面。共用 course.css：深色模式、手機寬度、表格可橫向捲動。
講師視角（整理既有結果）。學員視角：每步有可執行指令、驗收條件與常見失敗的修正方式。
